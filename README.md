# Caesar Cipher Tool

A web-based application built using Flask that allows users to encrypt, decrypt, and analyze text using the Caesar Cipher technique.

---

## Features

* Encrypt text with a custom shift value
* Decrypt text using a known shift
* Brute force mode to test all possible shifts
* Clean and responsive user interface

---

## Tech Stack

* Python (Flask)
* HTML, CSS
* Gunicorn (for deployment)

---

## Live Demo

https://caesar-cipher-tool-shcv.onrender.com

---

## Installation

1. Clone the repository
   git clone https://github.com/chandana-j77/caesar-cipher-tool.git

2. Navigate to the project folder
   cd caesar-cipher-tool

3. Install dependencies
   pip install -r requirements.txt

4. Run the application
   python app.py

5. Open in browser
   http://127.0.0.1:5000/

---

## Usage

* Enter text in the input field
* Select mode: Encrypt, Decrypt, or Brute Force
* Provide shift value (not required for brute force)
* View the result instantly

---

## Limitations

This tool is intended for educational purposes only. The Caesar Cipher is not secure for real-world encryption.
